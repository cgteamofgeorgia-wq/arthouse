BuildHub — API ტესტერი

ენდპოინტებს პირდაპირ ამ გვერდიდან იძახებს API — შეუმოწმებელი
გვერდი იტვირთება იმავე სერვერიდან, სადაც API მუშაობს — ამიტომ ცალკე მისამართი არ სჭირდება. გახსენით http://localhost:3000/test.html (ან დომენზე /test.html), როცა npm run dev გაშვებულია.

1. API-ის მისამართი

სერვერის მისამართი. თუ ბექენდი სხვა პორტზეა, შეცვალეთ — CORS ამ შემთხვევაში ბრაუზერის ბარიერია და ბექენდს ჰედერი სჭირდება. 

—

2. ავტორიზაცია

შესვლის შემდეგ ტოკენი ინახება ბრაუზერში და შემდეგი მოთხოვნები ავტომატურად ავტორიზებულია. სესია არ არის საჭირო საჯარო ენდპოინტებისთვის. 

—

3. კატალოგი

საჯაროა — ავტორიზაცია არ სჭირდება. ცარიელი შედეგი ნიშნავს, რომ Meilisearch ან ინდექსი ჯერ არ არის მზად.
